# 🛒 Retail Sales Performance Analysis

## 📊 Project Overview

The **Retail Sales Performance Analysis** project was built to understand the overall performance of a retail business by analyzing **sales, profit, product demand, category performance, and monthly trends**.

Retail businesses generate large amounts of transaction data, making it difficult to quickly identify which products and categories are performing well and where improvements are required. This project transforms raw sales data into an **interactive Excel dashboard** that provides clear and actionable business insights.

## 🎯 Why I Built This Project

The main purpose of this project was to answer important business questions:

- Which products are selling the most?
- Which categories generate the highest sales?
- Which categories contribute significantly to profit?
- How do sales and profit change month by month?
- How does performance vary across different years?
- Which areas require more attention to improve business performance?

Instead of manually analyzing raw data, I created a centralized dashboard where important information can be viewed and analyzed quickly.

## 💡 Solution

I cleaned and analyzed the retail sales dataset and developed an **interactive Excel dashboard** using:

- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards
- Sales & Profit Analysis
- Product & Category Analysis
- Monthly Trend Analysis

The dashboard allows users to filter the analysis by **Category, Month, and Year**, making it easier to explore specific areas of the business.

## 📈 Key Insights

The dashboard provides important performance metrics:

| KPI | Value |
|---|---:|
| Total Sales | ₹47.05 M |
| Total Profit | ₹22.42 M |
| Maximum Profit | ₹31.03 K |
| Average Sales | ₹5.11 K |

The analysis shows that **Apparel** is the highest-performing category by sales, followed by **Electronics** and **Home & Kitchen**.
